# 完整运行说明

先按 README 安装环境并执行 `download_model.py`。所有命令从仓库根目录执行；以下 PowerShell 示例用已经安装好依赖的 `.venv`。

## 数据准备

自行取得人民日报 1998 年 1 月、2 月的 GB18030 带音语料，将文件放入根目录 `1998语料/`，文件名分别含 `1998-01`、`1998-02`。实验使用的确切文件及 SHA-256 见 `results/data/`。每行需符合 `日期-版面-文章号-段落号 正文` 的编号格式。

```powershell
.\.venv\Scripts\python.exe revision_data.py
.\.venv\Scripts\python.exe prepare_classical.py
.\.venv\Scripts\python.exe -m unittest test_correctness -v
```

新克隆仓库不存在处理缓存时，准备脚本先生成 `data/processed` 的文章级划分，再生成 `data/v2`。已有缓存会保留其划分。原始语料没有随仓库再分发；《论语》参考数据由脚本按固定 commit 下载。

## 完整训练与测试

```powershell
.\.venv\Scripts\python.exe bert_punct.py train --config configs/corrected_seed42.json
.\.venv\Scripts\python.exe revision_train.py
.\.venv\Scripts\python.exe revision_evaluate.py
.\.venv\Scripts\python.exe revision_benchmark.py --repeats 7
.\.venv\Scripts\python.exe verify_gpu_edges.py
.\.venv\Scripts\python.exe revision_verify.py
```

第一条训练 seed42；第二条依次训练 seed43、seed44、weighted_seed42，已完成组会跳过。每组完整三轮，按验证 micro-F1 保存最佳权重。评测脚本固定从 seed42 两种配方选择，并保存逐字预测；种子复验不用于挑选最好的测试分数。

训练拒绝覆盖已完成的 run。如需重新实验，先备份结果并为四个配置指定新的 `run_dir`；评测与性能输出也需提前备份。审计脚本针对本报告语料规模与训练预算设计，换语料后的文档数或步数可能不满足其固定断言，应另定审计条件，而不是删除失败检查来宣称复现成功。

## 输出与报告

权重、完整日志与预测生成在 `runs/`，大文件不被 Git 跟踪。`results/` 保留的是本次已完成实验的轻量快照；重新运行不会自动把新实验结果覆盖到该目录。

仓库中的 `新实验报告.md` 是已完成实验的正式文档，图表随仓库提供。生成课程网站版（仅转换图片 URL，不改变实验内容）：

```powershell
.\.venv\Scripts\python.exe tools/export_course_report.py
```

输出为 `exports/新实验报告_课程网站版.md`。可以用 `--ref 提交SHA` 固定图片版本，用 `--output 路径` 自定义输出文件。网站是否允许外链图片，应在提交预览中确认，详见[图片引用说明](课程网站提交说明.md)。
